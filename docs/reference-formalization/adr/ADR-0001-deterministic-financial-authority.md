# ADR-0001: Deterministic Financial Authority Boundary

**Status:** Proposed — pending Q-001/Q-007 and security approval.

## Decision
AI, users, workflows and external inputs produce typed/versioned proposals only. A deterministic kernel recognizes a finite action vocabulary and evaluates pinned policy, legal disposition, risk, tenant/environment, capability and authorization. Unknown/stale/revoked inputs deny.

## Consequences
No model/provider has direct ledger, signing, network or adapter authority. Every action is explainable by proposal/policy/decision versions. Adding an action needs contract, threat, accounting and test review.
