# ADR-0009: Narrow Maturity Gates

**Status:** Proposed.

## Decision
Backtest, paper, testnet and mainnet gates unlock only the explicitly named environment/capability scope and time period. They do not imply legal, custody, provider, asset, security or operational readiness.

## Consequences
Every promotion needs distinct evidence and revalidation. Mainnet remains blocked until all readiness rows have operational proof; no aggregate “testnet passed” inference is allowed.
